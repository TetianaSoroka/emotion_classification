This project is a speech emotion recognition (SER) system that analyzes audio signals and predicts human emotions based on acoustic features. It provides fast, lightweight, and language-independent emotion detection.

Features:
- fast processing;
- audio feature extraction: Mel-spectrogram, ZCR (will be more);
- machine learning model: KNN, SGD, Random Forest (the best now, but will be more);
- emotion classes: Angry, Disgusted, Fearful, Happy, Neutral, Sad, Surprised;
- interactive UI built with Streamlit.

The model was trained on the "Emotions" dataset.
You can download the raw audio files here: https://www.kaggle.com/datasets/uldisvalainis/audio-emotions?resource=download-directory.
